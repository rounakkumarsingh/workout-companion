# Workout Companion — Design Context

## Users
Beginner lifters following the BTS Beginner 12-week hypertrophy program. They're on the gym floor, phone in one hand, between sets. Interaction pattern is quick glance-and-tap — log the set, move on. The app reduces gym anxiety and keeps them consistent by removing all logging friction.

## Brand Personality
**Dark. Focused. Powerful.** Voice is athletic, direct, no-nonsense — like a coach giving clear instructions. The app should feel like a premium gym: industrial, intense, and purposeful.

Emotional goals span the session arc:
- **Confidence + momentum** — visible progression data reinforces "I'm improving"
- **Flow state + intensity** — frictionless logging keeps the user in the zone
- **Calm + consistency** — clear structure reduces decision fatigue and gym anxiety

## Aesthetic Direction
- **Visual tone**: Dark-industrial. Gold accent (#e8c547) on deep black surfaces. Border-based layering (0.5px borders, no shadows). Data-dense, text-focused UI — no images in MVP.
- **Typography**: Barlow Condensed for all headings, exercise names, and CTAs (high-impact, compact, athletic). Space Mono for all numbers, timing, and stats (precision, measurement).
- **Theme**: Dark mode AND light mode support required. Status bar is light in dark mode.
- **Spacing**: 4px base unit grid. All values multiples of 4. Content padding from edges: 20px.
- **Animation**: Purposeful, short (100–500ms), never obstructive. Springs for physical button feel, smooth SVG arc transitions for progress/countdown, staggered entrances for celebration screens. Respect reduced-motion preference.
- **Anti-reference**: NOT social media — no feeds, likes, comments, or influencer content. Pure execution tool.

## Design Principles

1. **Minimize logging friction** — Every screen, tap, and animation serves one goal: log the set and move to the next. No unnecessary interactions. No loading spinners. The DB is synchronous (<2ms writes) — don't add artificial delays.

2. **Make progression visible** — Progress rings, streak counts, volume charts, PR detection. The user should see their improvement every session without digging for it. Progression is the primary motivator.

3. **Preserve workout focus** — The workout modal covers the full screen and hides tab navigation. No accidental exits. No swipe-back. The user is in "the zone" until they explicitly finish.

4. **Purposeful motion** — Every animation has a job: providing feedback (set logged), directing focus (active exercise scroll), celebrating (summary entrance). If an animation doesn't serve the gym context, remove it.

5. **Dark-industrial consistency** — 4px spacing grid, gold accent system, border-based elevation, athletic + mono font pairing. Every pixel follows the token system in `src/theme/tokens.ts`. No ad-hoc values.

6. **Offline-first, data-driven** — All data persists to local SQLite. Every screen fetches what it needs from the DB on mount. No global state library. No cloud dependency. The app works 100% offline.

7. **Respect the program** — The BTS Beginner program structure is the source of truth for workout scheduling, exercise selection, progression structure, and training split. Never invent alternative training systems.
