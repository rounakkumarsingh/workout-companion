# Session Anchor: Dev DB Clear Button

## What was done

- **Goal**: Add a dev-only button to truncate all DB tables.
- **Implementation**:
  - Added `clearAllTables()` to `src/db/client.ts` — iterates 8 tables with `PRAGMA foreign_keys = OFF`, deletes all rows, re-enables FK enforcement.
  - Added a `Dev: Clear DB` button at the bottom of the home screen in both the "ready" (Day 1 zero state) and "completed" (default workout preview) states.
  - Gated behind `__DEV__` — invisible in production builds.
  - Uses `Alert.alert` confirmation before executing.
  - On clear, resets to onboarding state.
- **Files changed**:
  - `src/db/client.ts` — added `clearAllTables()` export.
  - `app/(tabs)/home/index.tsx` — added import, dev button + styles in two render paths.
- **TypeScript**: `tsc --noEmit` passed cleanly.

## Context

The app uses expo-sqlite + drizzle-orm with these tables: `workout_sessions`, `exercise_logs`, `workout_set_logs`, `bodyweight_entries`, `cardio_sessions`, `progress_photos`, `app_settings`, `schema_version`. All have cascade deletes where applicable.

## Decision log

- Chose raw SQL `DELETE FROM` over Drizzle ORM for simplicity and guarantee of truncating all tables regardless of schema state.
- FK enforcement temporarily disabled to avoid ordering issues.
- Kept button subtle (muted small text) — dev tool, not a user feature.
- No new files created; minimal additions to existing files.
