# Weekly Prescriptions — BTS Beginner Program

Extracted from `docs/program.pdf`. Each week (1–12) lists the prescribed exercises for each training day with exact working set parameters. Organized by block, then week, then day.

---

## Conventions

| Field | Meaning |
|-------|---------|
| **Technique** | `N/A` (standard set) or `Failure` (taken to muscular failure) |
| **Warm-up** | Number of prescribed warm-up sets |
| **WS** | Working sets for this exercise this week |
| **Reps** | Target rep range |
| **Set RPE** | RPE target for early (non-last) working sets. `null` when WS = 1 |
| **Last RPE** | RPE target for the final working set |
| **Rest** | Rest period between working sets |

Days 3 (Optional Cardio/HIIT) and 7 (Full Rest) have no structured exercise prescriptions — they are not listed below.
